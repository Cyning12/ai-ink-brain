## 当日技术点小结

- **「证据」双通道**：**SSE** 上用户/调试可见的 `router.evidence`（+ 可选 details）与 **DB** 上默认开启的 `router_debug` / `router_trace_v1` 分层，满足 **在线排障** 与 **事后审计** 两种节奏。  
- **Text2SQL 可观测闭环**：执行摘要进入 **`text2sql_exec`**，与路由 trace **同挂载在 `metadata.router_debug`** 体系下，便于一条会话日志串起「为何选 SQL → 跑了什么 → 预览是什么」。  
- **稳健性**：Intent 边界（COUNT / 无 DDL）、SSE **序列化**与 **done 路径 NameError**、旧库 **无新列时的 insert 回退**，减少「一上线就断流」类事故。  
- **前后端同日对齐**：后端出帧 + 契约 + 测试；前端 **Timeline + Debug 开关 + `debug_router` 透传**，使证据链在 **开发态可复现、生产态可控量**。
